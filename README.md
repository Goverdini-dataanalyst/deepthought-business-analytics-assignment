1000 ICP Company Sourcing Plan (1 Month Project)

Objective

The aim of this project is to build a list of 1000 high-quality ICP companies in India within 1 month.

The focus is not just collecting company names, but finding real, relevant, and active businesses that match the required profile using data sources, AI tools, and filtering steps.

My Approach

Instead of manually searching companies one by one, I would build a simple system:

First collect a large list of companies
Then clean and organize the data
Then filter using rules and AI
Finally verify and select the best 1000 companies
